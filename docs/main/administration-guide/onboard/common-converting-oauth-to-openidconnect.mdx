Using the System Console, administrators can migrate an existing OAuth configuration to the OpenID Connect standard. A one-time conversion tool is available within the existing **OAuth 2.0** page. You can also go to **System Console \> Authentication \> OpenID Connect**.

Select **Convert to OpenID Connect** to migrate your active service provider configuration to the new standard. No further changes are required.

<Note>

\- Inactive service providers configured for OAuth 2.0 are also migrated to the new OpenID Connect standard.

</Note>
